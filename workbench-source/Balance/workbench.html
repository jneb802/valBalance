Loot balance

Scenario

Generate replaces the selected modifiers. Uses default Epic Loot effect counts and the bundled Star Level System snapshot; custom server settings and enchanting-table upgrades are not included. Choosing None clears all modifiers. Choosing another rarity keeps the current modifiers until you generate.

Tablet modifiers

Selected contributions add together to increase difficulty. Population contributions scale with strength divided by difficultyPer. Bosses/minibosses use extra counts per eligible wave; other population effects use percentages. Edit populationModifiers in the YAML for rarity ranges and divisors, and modifierDifficulty for contributions.
